### US-01

- **Phase ID:** US-01
- **Type:** user-story
- **Source UC:** UC-01, UC-02
- **Title:** As the coordinator, I want Requirements/Tech-Spec generation to stop writing an assembled file and validate/digest from in-memory assembled content instead, so that the split sources become the only thing generation ever produces
- **Commit type:** feat
- **Commit scope:** —
- **Commit subject:** stop pm-phase1.js from writing assembled Requirements/Tech-Spec; validate and digest in-memory

**Context:**

This phase is where generation itself stops relying on an assembled file: the regen/truncation
gates, the validator's own input, and `docsDigest` all move to the split sources in one coherent
change to `pm-phase1.js`, since splitting that rewrite across two different phases would mean two
unrelated phases both touching the same function bodies. The two agent-prompt tasks
(`gaia-validate-feature-docs`, `gaia-generate-tech-spec`) follow the exact contract `pm-phase1.js`'s
own tasks establish, so they are sequenced after the host-side change they depend on.

**Tasks in this phase:**

- `US-01-TASK-BE-01` — stop writing the assembled files; repoint the regen/truncation/AC-check gates
- `US-01-TASK-BE-02` — assemble in-memory for the validator's prompt and docsDigest
- `US-01-TASK-INFRA-01` — update the validator's own input contract to match
- `US-01-TASK-INFRA-02` — repoint the Tech-Spec agent's traceability read
- `US-01-TASK-TEST-01` — integration tests for all of the above

**Depends on phases:** none
