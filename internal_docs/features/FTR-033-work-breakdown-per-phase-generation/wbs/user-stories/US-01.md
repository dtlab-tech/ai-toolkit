### US-01

- **Phase ID:** US-01
- **Type:** user-story
- **Source UC:** UC-01, UC-02, UC-03
- **Title:** Split WBS Skeleton Generation Into Phase Enumeration and Per-Phase Task Generation
- **Commit type:** feat
- **Commit scope:** pm-phase2
- **Commit subject:** split WBS skeleton generation into phase enumeration and per-phase task generation

**Context:**

Replaces the single monolithic WBS skeleton call (which reliably times out on a real feature's
full task graph, confirmed by 12/12 consecutive failures independent of prompt size and dispatch
mechanism) with two bounded tiers: a lightweight phase-enumeration call, then one bounded call per
phase. The two new/narrowed agent files (INFRA-01, INFRA-02) must exist and be registered before
`pm-phase2.js` can dispatch either by name (BE-01). The shared test fixture must be upgraded
before any new or pre-existing `pm-phase2` test can pass against the new flow (TEST-01) — this is
why TEST-01 depends on all three implementation tasks rather than running in parallel.

**Tasks in this phase:**

- `US-01-TASK-INFRA-01` — Create gaia-generate-work-breakdown-phase.md agent and register it
- `US-01-TASK-INFRA-02` — Repurpose gaia-generate-work-breakdown.md to enumerate phases only
- `US-01-TASK-BE-01` — Split pm-phase2.js's skeleton call into enumeration + per-phase generation
- `US-01-TASK-TEST-01` — Cover per-phase WBS generation end to end, keep pre-existing tests passing
- `US-01-TASK-TEST-02` — Run the full regression suite and confirm no behavior regressed

**Depends on phases:** none
