### US-01

- **Phase ID:** US-01
- **Type:** user-story
- **Source UC:** UC-01
- **Title:** Recover a Schema-Required Response That Omits Optional Fix Flags
- **Commit type:** fix
- **Commit scope:** pm-phase1, workflow-control
- **Commit subject:** stop discarding a logically-complete validator response over two optional fix-routing booleans

**Context:**

Relaxes `gaia-validate-feature-docs`'s worker schema so `needsRequirementsFix`/`needsTechSpecFix`
are no longer required — confirmed, against three real evidence files, that the model reasonably
omits both when there is nothing to fix, and this alone recovers a valid payload with zero other
change. Also adds a bounded secondary retry (with a corrective nudge) for a genuinely different,
not-yet-evidenced failure shape.

**Tasks in this phase:**

- `US-01-TASK-BE-01` — Add a bounded, nudge-retried second trigger for a missing-structured-output response
- `US-01-TASK-BE-02` — Relax the feature-doc validator's schema to not require the fix-routing booleans
- `US-01-TASK-TEST-01` — Cover the missing-structured-output retry and nudge end to end
- `US-01-TASK-TEST-02` — Cover the relaxed validator schema end to end against the real pm-phase1 dispatch path

**Depends on phases:** none
