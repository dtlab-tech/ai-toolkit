### US-04

- **Phase ID:** US-04
- **Type:** user-story
- **Source UC:** UC-04
- **Title:** Fail Fast on an Invalid Per-Item Generation Result
- **Commit type:** feat
- **Commit scope:** pm-phase1
- **Commit subject:** fail fast on an invalid per-item generation result, with one bounded retry

**Context:**

A per-component/per-UC generation result is only ever validated on a LATER invocation's resume
check, or at final assembly — by which point every other item in the same run has already been
generated and paid for. Adds an immediate validity check (reusing FTR-027's own authoritative
`isValidComponentDetail`/`isValidUseCaseFile`) right after each item's own dispatch, with one
bounded retry before failing fast and attributably.

**Tasks in this phase:**

- `US-04-TASK-BE-01` — Validate a per-component generation result immediately, with one bounded retry
- `US-04-TASK-BE-02` — Validate a per-UC generation result immediately, with one bounded retry
- `US-04-TASK-TEST-01` — Cover fail-fast per-item validation end to end, both loops

**Depends on phases:** none
