**Context:**

into the wrong fields via a positional parser with no shape check. Adds a deterministic header
check — mirroring the one `wb-graph-checks.js` already has for the Work-Breakdown-side AC table —
run BEFORE the positional parse, plus a correction to the agent's own stale inline example.
