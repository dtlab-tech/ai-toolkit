### US-03

- **Phase ID:** US-03
- **Type:** user-story
- **Source UC:** UC-03
- **Title:** Drill Down on Components for Deep-Technical Claims
- **Commit type:** feat
- **Commit scope:** pm-phase1, agent-registry
- **Commit subject:** dispatch batched component-detail drill-down calls and fold their findings into the merge

**Context:**

Recovers the deep-technical coverage the skeleton-only prompt (US-01) can no longer see, without
reintroducing unbounded scale: a new narrow agent reads only the specific component files a
flagged claim actually needs, batched at a fixed size so even a pathological "most components
flagged" case stays bounded. Registration (agent-registry entry, new agent file, schema field)
lands first; dispatch/batching logic lands second, reusing US-02's merge mechanism.

- `US-03-TASK-BE-01` — Register the new component-detail drill-down agent and extend the validator's schema
- `US-03-TASK-BE-02` — Add fileSlug validation, dedup/batching, and drill-down dispatch to the validation cycle
- `US-03-TASK-TEST-01` — Cover component-detail drill-down dispatch, validation, dedup, and batching end to end
