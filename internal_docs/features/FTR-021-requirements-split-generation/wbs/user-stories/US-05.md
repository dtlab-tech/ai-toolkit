- **Commit type:** feat

**Context:**

This is the discovered-during-Tech-Spec counterpart to FTR-020's `wb-skeleton-check.js`: a
standalone CLI wrapper is required (not an inline `pm-phase1.js` helper) because `req-graph-checks.js`'s
pure functions still need their plain-object input parsed out of Markdown first, and
`pm-phase1.js` runs in a sandboxed runtime with no `require()` (see Tech-Spec §1) — any reusable
logic must be invoked via `c.command(['run-asset', ...])`, so the parsing step has to live in a
real script, not in the workflow file itself. Unlike FTR-020's placement of the analogous script
under its "assemble" user story, this one is placed under its own phase, sourced from UC-02
(Validate Skeleton Structurally) directly, since that is what it actually does.

**Tasks in this phase:**

- `US-05-TASK-BE-01` — create `req-skeleton-check.js` CLI wrapper
- `US-05-TASK-TEST-01` — tests for its 0/1/2 exit-code contract
