### US-03

- **Phase ID:** US-03
- **Type:** user-story
- **Source UC:** UC-03
- **Title:** As a user, I want to add a missing late child to an existing epic through define-feature, so that the epic is completed without a grilling round
- **Commit type:** feat
- **Commit scope:** —
- **Commit subject:** implement US-03 late child of an existing epic

**Context:**

UC-03 (Should) lets a user add one missing child to an existing epic through define-feature, with no grilling round, no standalone fallback and no register call. Prior phases already built the agent checkpoint, the skill relay, the apply initial-mode flow and the static test file. This phase adds the late-child path to the agent and to the skill, then pins both in the static tests. The agent comes first, then the skill, then the tests.

**Tasks in this phase:**

- `US-03-TASK-BE-01` — Add late-child epic lookup and status gate to the agent
- `US-03-TASK-BE-02` — Add late-child duplicate check and derived Summary and Keywords to the agent
- `US-03-TASK-BE-03` — Add late-child accept and reject handling to the agent
- `US-03-TASK-BE-04` — Add late-child routing and child prompt to the skill
- `US-03-TASK-BE-05` — Add late-child proposal relay and decision handling to the skill
- `US-03-TASK-TEST-01` — Add static tests pinning agent late-child text
- `US-03-TASK-TEST-02` — Add static tests pinning skill late-child text

**Depends on phases:** US-01, US-02
