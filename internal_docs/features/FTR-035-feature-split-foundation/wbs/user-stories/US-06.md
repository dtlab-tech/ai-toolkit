### US-06

- **Phase ID:** US-06
- **Type:** user-story
- **Source UC:** UC-06
- **Title:** As a Requirements or Tech-Spec generator agent, I want to read child and epic registry entries and epic.md so that standalone, child and epic features are classified correctly
- **Commit type:** feat
- **Commit scope:** —
- **Commit subject:** implement US-06 generator registry reader tolerance

**Context:**

This phase teaches the two generator agents to read the registry lines that FTR-035 introduces: Parent:, Depends on:, the epic status and the parent epic.md. It is read-side only and does not change generated output. The two agent edits are independent of each other. The static prompt-text test follows them, because it asserts the rules the agents now contain.

**Tasks in this phase:**

- `US-06-TASK-BE-01` — Add registry reader rules to requirements generator agent
- `US-06-TASK-BE-02` — Add registry reader rules to tech-spec generator agent
- `US-06-TASK-TEST-01` — Add registry reader tolerance test for generator agents

**Depends on phases:** none
