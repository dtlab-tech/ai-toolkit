### US-05

- **Phase ID:** US-05
- **Type:** user-story
- **Source UC:** UC-05
- **Title:** As a calling feature script, I want to register a standalone feature in the registry so that it is recorded once as defined
- **Commit type:** feat
- **Commit scope:** —
- **Commit subject:** implement US-05 register standalone feature

**Context:**

US-05 adds the `register` path that records a standalone feature once, with status `defined`. It reuses the registry read, entry render, temp-and-rename write and first-sentence helpers that earlier phases built, so no registry primitive is re-implemented. The tasks go in order: the feature.md reader, the register function, the facade wiring, then the tests. The open status and keyword questions follow the Tech-Spec interim rules (REGISTRY_STATUS refusal; empty Keywords written as an empty line).

**Tasks in this phase:**

- `US-05-TASK-BE-01` — Add feature.md reader for register
- `US-05-TASK-BE-02` — Add and export register function
- `US-05-TASK-BE-03` — Wire facade register command
- `US-05-TASK-TEST-01` — Add register success and registry-creation tests
- `US-05-TASK-TEST-02` — Add register idempotence and foreign status tests
- `US-05-TASK-TEST-03` — Add register write-failure test
- `US-05-TASK-TEST-04` — Add facade register stdout and exit tests

**Depends on phases:** INFRA, US-04
