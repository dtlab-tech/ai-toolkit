### US-02

- **Phase ID:** US-02
- **Type:** user-story
- **Source UC:** UC-02
- **Title:** As the coordinator, I want a script that computes AC-to-task-to-phase coverage and renders it as a Markdown table, so that traceability already enforced by wb-validate.js becomes visible without any new LLM call
- **Commit type:** feat
- **Commit scope:** —
- **Commit subject:** implement US-02 ac-task-matrix computation and rendering

**Context:**

This is the feature's actual deliverable — everything else exists to feed it (US-01) or expose it
(US-03). `computeCoverage` deliberately mirrors `checkAcCoverage`'s own traversal (phase → task →
`acceptanceCriteria`) rather than introducing a different algorithm, since the whole point of this
feature is that the matrix must show exactly what `wb-validate.js` already enforces — a different
traversal risks the two silently disagreeing on some edge case.

**Tasks in this phase:**

- `US-02-TASK-BE-01` — `computeCoverage`/`renderMatrix`/CLI entry point
- `US-02-TASK-TEST-01` — unit tests (multi-task, multi-phase, unscoped, zero-coverage, ordering)
