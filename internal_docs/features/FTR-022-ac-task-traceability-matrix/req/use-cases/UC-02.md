### UC-02: Compute AC↔Task↔Phase Coverage and Render the Matrix

| Field | Value |
|---|---|
| Actor | `ac-task-matrix.js` |
| Priority | Must |
| Preconditions | UC-01's `acMap` available; Work Breakdown loadable via `loadWorkBreakdown` |
| Trigger | After UC-01 |

For every AC in `acMap`, the script walks every phase's tasks (the same traversal
`checkAcCoverage` already does, read-only and side-effect-free here) to find every task whose
`acceptanceCriteria` array cites that AC ID, and that task's owning phase ID. It renders one
Markdown table — AC ID, Criterion, Priority, Related UC, covering Task ID(s), covering Phase(s) —
in the Requirements AC table's own row order, followed by a legend, to
`{PREFIX}-AC-Task-Matrix.md`.

**Related Business Rules:** BR-01, BR-02, BR-04 (see [index.md](../index.md#3-business-rules))

**Related Acceptance Criteria:** AC-01, AC-02, AC-03, AC-04, AC-05, AC-06 (see [index.md](../index.md#7-acceptance-criteria))
