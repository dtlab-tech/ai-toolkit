### UC-01: Parse the Requirements Acceptance Criteria Table (with Criterion Text)

| Field | Value |
|---|---|
| Actor | `ac-task-matrix.js`, via `wb-graph-checks.js`'s `parseAcTable` |
| Priority | Must |
| Preconditions | `{PREFIX}-Requirements.md` exists and has a `## 7. Acceptance Criteria` section |
| Trigger | `ac-task-matrix.js` is invoked |

`parseAcTable` is extended to also capture each row's `Criterion` column (today it only retains
`priority`, `allowedUserStories`, `unscoped` per AC) and return it as part of each `acMap` entry.
This is additive: every existing caller (`checkAcCoverage` and its three checks 19–21) continues
to read exactly the fields it already reads; nothing about its existing behavior changes.

**Related Acceptance Criteria:** AC-05, AC-06 (see [index.md](../index.md#7-acceptance-criteria))
