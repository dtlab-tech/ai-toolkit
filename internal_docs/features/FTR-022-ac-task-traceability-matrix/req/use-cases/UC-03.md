### UC-03: Wire Matrix Generation into pm-phase2.js's Gate 2 Flow

| Field | Value |
|---|---|
| Actor | Coordinator (`pm-phase2.js`) |
| Priority | Must |
| Preconditions | The existing `wb-render.js` step has completed |
| Trigger | Immediately after the existing `wb-render.js` call |

`pm-phase2.js` invokes `ac-task-matrix.js` via `c.command(['run-asset',
'scripts/ac-task-matrix.js', '--project', c.root, '--', wbsDir, file('Requirements.md'),
prefix])`, reads the produced file back (never trusting an unread write), and includes its path in
the Gate 2 payload alongside the existing `renderer_result`. No new pass/fail branch is
introduced — this step cannot fail for a feature that already passed `wb-validate.js`, since every
fact it renders was already validated before this step runs.
