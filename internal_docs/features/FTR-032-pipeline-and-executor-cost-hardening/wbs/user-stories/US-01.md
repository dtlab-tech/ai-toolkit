### US-01

- **Phase ID:** US-01
- **Type:** user-story
- **Source UC:** UC-01
- **Title:** Shrink the WBS Skeleton Call to Index-Row Weight
- **Commit type:** fix
- **Commit scope:** pm-phase2, wbs-assembler
- **Commit subject:** stop asking the WBS skeleton call for an effort estimate it already gets from the per-task detail call

**Context:**

Removes the per-task effort estimate from `pm-phase2.js`'s WBS skeleton schema and starts reading
it back from the per-task detail call's existing response instead of silently discarding it — that
call's own template already produces a real estimate today, so this requires no new prompt text
anywhere, only trusting a value the model already writes. `wbs-assembler.js` must change first
(the read-back side) before `pm-phase2.js` can safely stop producing the field (the write side).

**Tasks in this phase:**

- `US-01-TASK-BE-01` — Read the per-task effort estimate back from its own detail response
- `US-01-TASK-BE-02` — Remove the per-task effort estimate from the WBS skeleton schema
- `US-01-TASK-TEST-01` — Cover the skeleton/detail estimate boundary move end to end

**Depends on phases:** none
