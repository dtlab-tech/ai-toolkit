### US-02

- **Phase ID:** US-02
- **Type:** user-story
- **Source UC:** UC-02
- **Title:** Persist Turn-by-Turn Dispatch Evidence for Implementation/Review
- **Commit type:** feat
- **Commit scope:** task-executor
- **Commit subject:** persist turn-by-turn evidence for every implementation and review dispatch

**Context:**

Reuses `lib/workflow-worker-evidence.js`'s existing `createEvidence`/`save` primitive (the same one
`pm-phase1`/`pm-phase2` already use for their own worker calls) so a real implementation or review
dispatch leaves behind an inspectable transcript, independent of this feature's own cost
investigation — it captures the raw material for a future investigation, it does not itself
diagnose anything.

**Tasks in this phase:**

- `US-02-TASK-BE-01` — Persist evidence for implementation and review dispatches
- `US-02-TASK-TEST-01` — Cover dispatch evidence capture end to end

**Depends on phases:** none
