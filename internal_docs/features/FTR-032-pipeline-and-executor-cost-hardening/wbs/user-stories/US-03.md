### US-03

- **Phase ID:** US-03
- **Type:** user-story
- **Source UC:** UC-03
- **Title:** Short-Circuit Dispatch for an Already-Satisfied Task
- **Commit type:** feat
- **Commit scope:** task-executor
- **Commit subject:** skip implementation/review dispatch entirely for a task already satisfied before its first attempt

**Context:**

Runs a task's own verification commands once, before its first attempt only, so a task whose
deliverable already exists (e.g. a prior commit, a prerequisite task) never pays for a full
implementation + review dispatch cycle just to discover there is nothing to do — reported at ~20
minutes of real cost on a real 4-line no-op task. `store.js` must change first (the `reason`
parameter the short-circuit needs to record) before `index.js`'s own dispatch loop can use it.

**Tasks in this phase:**

- `US-03-TASK-BE-01` — Let setTaskStatus record an optional reason alongside a task's status
- `US-03-TASK-BE-02` — Short-circuit dispatch for a task already satisfied before its first attempt
- `US-03-TASK-TEST-01` — Cover the pre-dispatch short-circuit end to end

**Depends on phases:** none
